BEAUTY N BEAT — BÀI TẬP LỚN HỆ THỐNG VÀ CÔNG NGHỆ WEB

1. Giải nén toàn bộ thư mục BeautyNBeat, giữ nguyên thư mục assets.
2. Mở index.html để xem website. Nên dùng Live Server trong Visual Studio Code
   khi thử luồng qua nhiều trang; giữ cùng một địa chỉ truy cập để dùng chung dữ liệu.
3. Có 12 trang HTML. CSS, JavaScript, hình ảnh và thư viện được lưu trong assets.
4. Tự đăng ký một tài khoản ở trang Đăng ký để thử đăng nhập.
5. Chọn sản phẩm → thêm vào giỏ → sửa số lượng → tiến hành thanh toán.
   Nhập thông tin hợp lệ rồi xác nhận để tạo đơn mô phỏng.

PHẠM VI
Website thực hành HTML, CSS, Bootstrap 5, JavaScript, jQuery và Regex.
Tài khoản, giỏ hàng, đơn hàng được lưu trên trình duyệt; chưa có máy chủ.
Thanh toán và vận chuyển chỉ mô phỏng, không phát sinh giao dịch thật.
Các bản sao từng phần A–F được giữ riêng ngoài gói này để tiện đối chiếu.
